# 🧮 문자열 계산기

### 📝 구현할 기능 목록
- [X] 문자열을 입력받는다.
- [X] 쉼표(,) 또는 콜론(:) 구분자를 기준으로 문자열을 분리한다.
- [X] 각 문자열을 숫자로 변환 후 합을 반환한다.
- [X] "//"와 "\n" 사이에 위치하는 문자를 커스텀 구분자로 사용한다.
- [X] 사용자가 잘못된 값을 입력할 경우 `IllegalArgumentException`을 발생시킨 후 애플리케이션을 종료시킨다.
  - 음수를 입력한 경우
  - 숫자가 아닌 경우
- [X] 입력값이 없거나 공백일 경우 0을 반환한다.
- [X] 하나의 숫자만 입력하였을 경우 해당 숫자를 그대로 반환한다.
